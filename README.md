# Pedro Vinícius · site pessoal

**No ar em [pedro-vinicius-ma.github.io](https://pedro-vinicius-ma.github.io)**

Este é o código do meu site profissional. Sou desenvolvedor full stack e perito judicial em Caruaru-PE. Construo sistemas web sob medida, dashboards de BI, automações e agentes de IA, e faço testes de segurança em sites, sistemas e redes.

## O que tem no site

- **Serviços com preço inicial:** automação, BI, agentes de IA, sistemas web, sites-cartão de visita, segurança (pentest, redes Wi-Fi e LGPD) e perícia grafotécnica.
- **Casos reais:** cada um descrito como problema, solução e resultado. Alguns clientes pediram sigilo; nesses casos o site mostra o tipo de trabalho, sem nomes.
- **Código aberto:** projetos que estão aqui no GitHub.
- **Orçamento:** um formulário que monta a mensagem e abre direto no WhatsApp.
- **Português e inglês,** com botão para trocar o idioma, e tema claro ou escuro conforme o sistema de quem visita.

## Quer um site assim?

Este site também é um serviço. Faço sites-cartão de visita como este para profissionais e empresas, a partir de R$ 1.200. O site inclui:

- serviços, preços, trabalhos e contatos;
- pedido de orçamento direto no WhatsApp;
- versão em português e inglês;
- tema claro e escuro;
- layout pronto para celular.

A hospedagem pode ser gratuita, como esta no GitHub Pages; o domínio próprio fica à parte.

## Como foi feito

É um único `index.html`, sem framework e sem etapa de build:

- **HTML, CSS e JavaScript puros**, num arquivo de uns 70 KB.
- **Ilustrações dos casos em SVG** desenhadas à mão, direto no HTML.
- **Fontes do Google Fonts:** Archivo, IBM Plex Sans e IBM Plex Mono.
- **Formulário sem servidor:** ele monta um link `wa.me` e não guarda dado nenhum.
- **Hospedagem no GitHub Pages.**

Para rodar na sua máquina:

```bash
git clone https://github.com/Pedro-Vinicius-MA/Pedro-Vinicius-MA.github.io
cd Pedro-Vinicius-MA.github.io
python3 -m http.server 8000   # depois abra http://localhost:8000
```
